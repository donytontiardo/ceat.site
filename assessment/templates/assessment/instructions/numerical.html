You are given numbers that are linked to each other along the rows and down the columns. Some numbers are hidden behind a dash (-) and one is replaced by a question mark (?). Use everything you can see to work out the number behind the question mark.

Example

The answer is 4. The top row counts 1, 2, 3, 4, and each number in the top row is half of the one below it, just as 3 is half of 6. Answering 4 links all the numbers logically.

You have 8 minutes to answer as many questions as you can. Type the number in the answer box.
